# Como testar a API

1. No terminal, dentro da pasta do projeto, execute:

   ```bash
   go run .
   ```

2. Abra no navegador: <http://localhost:8080/teste>

3. Use os formulários para cadastrar salas, alunos e turmas. Depois teste matrículas, alocações e consultas.

As respostas da API, com o código HTTP e o JSON, aparecem no painel **Resposta**. Os dados ficam em memória e são apagados quando o programa é encerrado.
